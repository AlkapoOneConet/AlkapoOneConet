# Política de seguridad

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad en este repositorio o en alguno de sus proyectos relacionados, evita publicar detalles técnicos en un issue público. Contacta al propietario del repositorio mediante un canal privado de GitHub y proporciona:

- Descripción del problema.
- Pasos para reproducirlo.
- Impacto potencial.
- Evidencia no sensible.
- Una sugerencia de mitigación, si está disponible.

No incluyas credenciales, tokens, datos personales ni información de terceros en el reporte.

## Alcance responsable

Las pruebas de seguridad deben realizarse únicamente sobre sistemas propios o con autorización explícita y dentro de un alcance definido. No se permite el acceso no autorizado, la extracción de datos ni la interrupción de servicios.
